1. WHAT THIS SCRIPT DOES
------------------------
When executed, 'generate_tz_map.py' automatically generates four distinct, 
high-resolution reference documents in both PDF and PNG formats:

  * Document 1 (Doc1_50_States_Time_Zone_Map): 
    A grid map of all 50 U.S. states displaying active local abbreviations, 
    UTC offsets, DST status, and split-state indicator asterisks (*).

  * Document 2 (Doc2_5_Territories_Time_Zone_Map): 
    Standalone reference cards for the 5 inhabited U.S. territories 
    (Guam, Puerto Rico, U.S. Virgin Islands, American Samoa, MP).

  * Document 3 (Doc3_Combined_Master_Time_Zone_Map): 
    A combined master poster featuring all 50 states and inset cards 
    for all 5 territories.

  * Document 4 (Doc4_Granular_Time_Zone_Table): 
    A portrait-oriented reference table detailing all primary state time 
    zones alongside all 15 split-zone cities and counties across the nation.


2. PREREQUISITES & SETUP
------------------------
Python version 3.9 or newer is recommended.

Install the required visualization and time zone libraries via terminal/command prompt:

  pip install matplotlib tzdata

(Modules like 'datetime', 'zoneinfo', 'urllib', 'xml', and 'textwrap' are 
built into Python's standard library).


3. HOW TO RUN THE SCRIPT
------------------------
1. Save the complete Python code as 'generate_tz_map.py' in your project folder.
2. Open your Terminal or Command Prompt.
3. Navigate to the directory containing 'generate_tz_map.py'.
4. Run the following command:

  python generate_tz_map.py


4. WHAT HAPPENS DURING EXECUTION
---------------------------------
  a) Auto-Update Check (auto_update_tzdata): 
     The script silently checks PyPI for the newest official IANA time zone 
     database release and updates it in the background automatically.

  b) NIST Clock Sync (get_nist_metadata): 
     The script attempts to connect to nist.time.gov to verify atomic time. 
     If offline, it smoothly transitions to your system clock without failing.

  c) Live Offset & DST Calculation: 
     Python's 'zoneinfo' engine computes exact local offsets for today's date.

  d) Deliverables Output: 
     All 8 files (4 PDFs and 4 PNGs) are generated and saved to your current folder.


5. OUTPUT FILE DELIVERABLES
---------------------------
  - Doc1_50_States_Time_Zone_Map (.pdf / .png)

6. TROUBLESHOOTING & NOTES
--------------------------
  - "Source: Offline (Local Clock Fallback)": If Document 4 displays this note, 
    your network or firewall blocked the outbound ping to nist.time.gov. The 
    documents remain 100% accurate because the updated IANA rules and system clock 
    are used automatically.
